Connect the ESP32-S3 board over USB and click below to flash the latest firmware.

Want a different dial? Design your own in the face editor.

Requires Chrome or Edge. Firefox and Safari do not implement WebSerial, so flashing from the browser will not work there.

If the board is not detected, hold BOOT while pressing RESET to force download mode.

Prefer the command line? Download ai-gauge-merged.bin from the releases page and run esptool.py --chip esp32s3 write_flash 0x0 ai-gauge-merged.bin.
